# Code and experimental evidence

- `gan_project_source.zip`: source package, configurations, tests, and Colab launcher. It excludes datasets and trained models.
- `experiment_evidence.zip`: completed runs, figures, metrics, logs, source snapshots, and all 17 final training checkpoints. Its manifest checksums every archived file.
- `SHA256SUMS`: checksums for these files and this guide.

Training used local CPU and Apple MPS. The Colab notebook supports CUDA and Drive recovery, but no signed-in cloud session was run here.

Use the project README and docs/PROJECT_GUIDE.md to reproduce experiments and inspect the results.
